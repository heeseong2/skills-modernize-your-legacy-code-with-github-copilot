# Student Account Management Test Plan

This plan captures observable behavior in the current COBOL application for stakeholder review and as a basis for Node.js unit and integration tests. Expected results describe current implementation behavior, not necessarily approved business policy. Cases marked for stakeholder confirmation should be resolved before treating that behavior as a requirement for the Node.js version.

`Actual Result` and `Status` are `Not run` until the case is executed. After execution, record the observed result and change the status to `Pass` or `Fail`.

Expected balance amounts are numeric values. Console output is zero-padded to six integer digits (for example, `001000.00`).
